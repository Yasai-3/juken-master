# 中学受験マスター 2（AI作問 ＆ 弱点コーチング・ハイブリッドPWA）

中学受験向けの理科・社会を効率よく学習できるスタンドアローン・オフライン対応アプリです。

## 🚀 起動方法（2通りの使い方）

### 方法A：サーバー不要！単一HTMLファイルをダブルクリックして使う（最も手軽）
フォルダ内の **`中学受験マスター2_スタンドアローン.html`** をダブルクリックするだけで、Macのブラウザ上でそのまま動作します。
- このHTMLファイル1つをAndroidタブレットにコピーして開くだけでも動作します。

### 方法B：PWAサーバーとして起動する（Mac ＆ 同一Wi-FiのAndroidタブレットで共有）
1. フォルダ内の **`アプリを起動.command`** をダブルクリックします（またはターミナルで `npm run preview -- --host` を実行）。
2. Macでブラウザが自動的に開きます（`http://localhost:4173`）。
3. 同じWi-FiにつないだAndroidタブレットのChromeで、ターミナルに表示される `Network: http://192.168.x.x:4173/` のアドレスを開き、メニューから「ホーム画面に追加」を選ぶと、タブレット内にオフラインアプリ（PWA）としてインストールされます。

---

## ✨ 主な機能

1. **AI作問スタジオ（画像・PDF読み込み）**
   - 「✨ AI作問スタジオ（画像・PDF読込）/ 管理」ボタンから、塾のテキストやプリントの写真（JPG/PNG）・PDFをドラッグ＆ドロップで読み込みます。
   - **難易度（基礎・標準・応用）** と **問題形式（4択選択・一問一答語句入力・短文記述）** を選んで、Gemini APIで良質な問題を一括生成できます。
2. **3種類の出題形式 ＆ オフライン自動採点**
   - **4択選択問題**: 選択肢シャッフル対応
   - **一問一答・語句入力問題**: 表記ゆれや「ひらがな正解・漢字指定」を自動判定
   - **短文記述問題**: 必須キーワードが含まれているかを自動チェックして採点（別の表現で合っている場合の自己採点補正ボタン付き）
3. **成績分析 ＆「今後どの問題・知識を伸ばせばよいか」の学習アドバイス**
   - 「4択はできるが語句入力で取りこぼしている」「基礎は定着したので応用・記述へ進もう」といった具体的なアドバイスと、**優先して伸ばすべき単元・知識テーマ TOP 5** をオフラインで常時診断します。
   - ネット接続時には、Gemini AIによる「専属コーチ診断レポート」もワンクリックで作成・保存できます。
4. **旧「作問アプリ１」との完全データ互換**
   - 「📲 タブレット連携・保存/設定」タブから、以前のアプリで保存したJSONバックアップファイルもそのまま読み込んで統合できます。
